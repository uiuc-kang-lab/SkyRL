To solve this problem, we need to determine whether the Major Oak tree will have an even number of leaves in a given year \( n \). The leaves grow each year and last for \( k \) years, so we need to check the parity of the sum of leaves added in the range from \( \max(1, n - k + 1) \) to \( n \).

### Approach
1. **Identify the Range**: For each year \( n \), the leaves added start from \( \max(1, n - k + 1) \) and end at \( n \).
2. **Check Parity of Leaf Counts**: The leaves added in year \( i \) are \( i^i \). These leaves contribute to the total leaf count from year \( i \) to \( i + k - 1 \). Therefore, we need to determine if the sum of leaves in year \( n \) is even.
3. **Count Odd Leaves**: The sum of leaves in year \( n \) is even if there is an even number of odd terms in the range from \( \max(1, n - k + 1) \) to \( n \). This is because each odd term contributes 1 to the sum's parity, while even terms contribute 0.
4. **Efficient Calculation**: Instead of iterating through each year, we calculate the number of odd numbers in the range using mathematical properties. This allows us to determine the parity efficiently.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    a = max(1, n - k + 1)
    b = n
    if a > b:
        print("NO")
    else:
        first_odd = a if a % 2 == 1 else a + 1
        last_odd = b if b % 2 == 1 else b - 1
        if first_odd > last_odd:
            count = 0
        else:
            count = (last_odd - first_odd) // 2 + 1
        if count % 2 == 0:
            print("YES")
        else:
            print("NO")
```

### Explanation
1. **Reading Input**: We start by reading the number of test cases \( t \).
2. **Loop Through Test Cases**: For each test case, read \( n \) and \( k \).
3. **Determine Range**: Calculate the starting year \( a \) as \( \max(1, n - k + 1) \) and the ending year \( b \) as \( n \).
4. **Check Range Validity**: If \( a \) is greater than \( b \), the range is invalid, and we output "NO".
5. **Find Odd Numbers**: Calculate the first and last odd numbers in the range. If the first odd is greater than the last odd, there are no odd numbers, so output "NO".
6. **Count Odd Numbers**: If there are odd numbers, count them and check if the count is even. If even, output "YES"; otherwise, output "NO".

This approach efficiently determines the parity of the leaf count without iterating through each year, making it suitable for large values of \( n \) and \( k \).<｜end▁of▁sentence｜>
