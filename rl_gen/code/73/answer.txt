To solve this problem, we need to determine the minimum number of colors required to color an \( n \times m \) grid such that any two cells of the same color are at least \( k \) distance apart in terms of Manhattan distance. 

### Approach
The key insight is to recognize that each color class must form a set of cells where each cell is at least \( k \) units away from any other cell of the same color in both the x and y directions. This can be efficiently determined by dividing the grid into blocks of size \( k \times k \). The minimum number of colors required is determined by the maximum number of such blocks needed in either the row or column dimension.

1. **Calculate the number of blocks in rows**: This is given by the ceiling of \( n \) divided by \( k \), which can be computed as \((n + k - 1) // k\).
2. **Calculate the number of blocks in columns**: Similarly, this is given by the ceiling of \( m \) divided by \( k \), computed as \((m + k - 1) // k\).
3. **Determine the minimum number of colors**: The minimum number of colors required is the maximum of the number of blocks in rows and columns.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n, m, k = map(int, input().split())
    a = (n + k - 1) // k
    b = (m + k - 1) // k
    print(max(a, b))
```

### Explanation
- **Input Reading**: The code reads the number of test cases and then processes each test case individually.
- **Block Calculation**: For each grid dimension (rows and columns), the code calculates the number of blocks needed by dividing the dimension by \( k \) and taking the ceiling of the result using integer arithmetic.
- **Determine Colors**: The minimum number of colors is the maximum of the number of blocks needed in rows and columns, ensuring that all cells of the same color are sufficiently distant apart.
