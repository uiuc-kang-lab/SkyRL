To solve this problem, we need to construct an array of positive nonzero integers such that for every integer \( k \) from 1 to \( n \), the sum of the elements at positions that are multiples of \( k \) is divisible by \( k \). Each element in the array must be less than or equal to \( 10^5 \).

### Approach
The key insight is to recognize that each element in the array can be set to its position index. This ensures that for each \( k \), the sum of elements at positions that are multiples of \( k \) is exactly \( k \) times the sum of the first \( m \) natural numbers, where \( m \) is the number of multiples of \( k \) up to \( n \). This sum is always divisible by \( k \).

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    print(' '.join(map(str, list(range(1, n+1)))))
```

### Explanation
1. **Reading Input:** We first read the number of test cases \( t \).
2. **Constructing the Array:** For each test case, we read the integer \( n \) and construct an array where each element at position \( i \) (1-based index) is equal to \( i \). This means the array will be [1, 2, 3, ..., n].
3. **Output:** We print the constructed array for each test case.

This approach ensures that the sum of elements at positions that are multiples of any \( k \) from 1 to \( n \) is a multiple of \( k \), thus satisfying the problem's requirements. The time complexity for each test case is \( O(n) \), which is efficient given the constraints.<｜end▁of▁sentence｜>
