To solve this problem, we need to determine the minimum time required for Zhan to blend all the fruits using a blender. The blender can blend up to `x` fruits per second, but can only blend the minimum of `x` or the number of fruits inside it per second. Zhan can add up to `y` fruits per second into the blender per second.

### Approach
1. **Problem Analysis**:
   - Each second, Zhan can add up to `y` fruits into the blender.
   - After each addition, the blender blends the minimum of `x` or the current number of fruits.
   - The goal is to find the minimum time required to blend all `n` fruits.

2. **Key Insights**:
   - If `y` is greater than or equal to `x`, each addition of `y` fruits will not reduce the number of fruits in the blender, making it impossible to reduce the count further. Thus, if `y >= x` and `n > 0`, it is impossible to blend all fruits.
   - If `y` is less than `x`, each addition of `y` fruits will cause the count to decrease after blending. The reduction in the count per step is `x - y`.

3. **Algorithm**:
   - For each test case, read the values of `n`, `x`, and `y`.
   - If `n` is 0, the time is 0.
   - If `y >= x`, it is impossible to blend all fruits, so the time is -1 (or some indication of impossibility).
   - Otherwise, calculate the minimum time using the formula `(n + (x - y) - 1) // (x - y)` to determine the number of steps required.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    x = int(input())
    y = int(input())
    if n == 0:
        print(0)
    elif y >= x:
        print(-1)
    else:
        steps = (n + (x - y) - 1) // (x - y)
        print(steps)
```

### Explanation
- **Reading Input**: The code reads multiple test cases.
- **Handling Special Cases**: If `n` is 0, the time is 0. If `y` is greater than or equal to `x`, it is impossible to blend all fruits, so the result is -1.
- **Calculating Steps**: For each valid case where `y < x`, the formula `(n + (x - y) - 1) // (x - y)` is used to determine the minimum time required to blend all fruits by considering the reduction in the count of fruits after each addition and blending step.
