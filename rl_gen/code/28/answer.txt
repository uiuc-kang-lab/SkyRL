To solve this problem, we need to determine the number of subsegments of mushrooms such that the final value of the toxicity level \( g \) is not zero. The toxicity level \( g \) starts at 0 and increases as we process each mushroom in the subsegment. If adding a mushroom's toxicity level causes \( g \) to exceed a given maximum value \( x \), \( g \) is reset to 0 and the process continues.

### Approach
1. **Problem Analysis**: The key observation is that the final value of \( g \) will be non-zero if and only if the sum of the toxicity levels in the subsegment does not exceed \( x \). This is because if the sum exceeds \( x \), \( g \) will be reset to zero.
2. **Sliding Window Technique**: We use a sliding window approach to efficiently count the number of valid subsegments. The window is defined by two pointers, `left` and `right`, which denote the current subsegment being considered.
3. **Sum Calculation**: For each position `right`, we maintain a running sum of the current subsegment. If this sum exceeds \( x \), we move the `left` pointer forward until the sum is within the limit.
4. **Count Valid Subsegments**: For each position `right`, the number of valid subsegments ending at `right` is the number of valid starting points from `left` to `right`.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    for _ in range(t):
        n, x = int(data[idx]), int(data[idx + 1])
        idx += 2
        a = list(map(int, data[idx:idx + n]))
        idx += n
        left = 0
        sum_current = 0
        count = 0
        for right in range(n):
            sum_current += a[right]
            while sum_current > x and left <= right:
                sum_current -= a[left]
                left += 1
            count += (right - left + 1)
        print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Initialization**: For each test case, initialize `left` to 0, `sum_current` to 0, and `count` to 0.
3. **Iterate Over Subsegments**: For each position `right`, add the toxicity level of the current mushroom to `sum_current`.
4. **Adjust Window**: If `sum_current` exceeds \( x \), move the `left` pointer forward until `sum_current` is within the limit.
5. **Count Valid Subsegments**: The number of valid subsegments ending at `right` is the number of valid starting points from `left` to `right`, which is calculated as `right - left + 1`.
