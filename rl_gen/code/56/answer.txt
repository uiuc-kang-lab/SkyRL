To solve this problem, we need to determine if all passengers followed the recommended seating rules in a bus. The bus has `n` seats numbered from 1 to `n`, and passengers board following specific rules. The goal is to check if each passenger sat in a seat that meets the recommendation.

### Approach
1. **Problem Analysis**: The rules state that a passenger can sit in a free seat if at least one of the neighboring seats (left or right) is occupied. If a passenger sits in a seat with no occupied neighbors, they did not follow the rule.
2. **Intuition**: For each passenger, after they sit down, we need to check if their seat is adjacent (in terms of seat numbers) to any of the previously occupied seats. If not, they did not follow the rule.
3. **Algorithm**: 
   - For each test case, read the number of seats `n` and the array `a` which contains the seat numbers in the order passengers boarded.
   - Use a set to keep track of the occupied seats.
   - For each seat in the array `a`, check if the seat is adjacent to any previously occupied seat. If not, mark the test case as invalid.
4. **Complexity**: The algorithm runs in O(n) time for each test case, where `n` is the number of seats. This is efficient given the constraints.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        a = list(map(int, sys.stdin.readline().split()))
        taken = set()
        valid = True
        for seat in a:
            if (seat - 1) in taken or (seat + 1) in taken:
                continue
            else:
                valid = False
                break
        print("YES" if valid else "NO")

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The code reads multiple test cases. For each test case, it reads the number of seats `n` and the array `a` which indicates the seat numbers in the order passengers boarded.
- **Tracking Occupied Seats**: A set `taken` is used to keep track of the seats that have been occupied.
- **Checking Adjacency**: For each seat in the array `a`, the code checks if the seat is adjacent to any previously occupied seat. If not, the test case is marked invalid.
- **Output**: After processing all seats for a test case, the result is printed as "YES" if all passengers followed the rules, otherwise "NO".

This approach ensures that we efficiently check each seat in linear time, making the solution both optimal and easy to understand.<｜end▁of▁sentence｜>
