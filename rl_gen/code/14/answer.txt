To solve this problem, we need to determine how many people Robin Hood will take gold from based on their gold holdings. Robin Hood takes all the gold from people who have at least a certain threshold, and gives 1 gold to people who have no gold.

### Approach
1. **Problem Analysis**: Robin Hood takes all the gold from people whose gold is at least a given threshold `k`. For people with zero gold, he gives 1 gold if he has any gold. Thus, we need to count the number of people whose gold is exactly zero and less than `k`.

2. **Intuition**: For each person, if their gold is zero and less than `k`, they contribute to the count of people who will receive gold. Otherwise, they do not.

3. **Algorithm**:
   - Read the number of test cases.
   - For each test case, read the number of people `n` and the threshold `k`.
   - Read the list of gold values for each person.
   - Count how many people have zero gold and are below the threshold `k`.

4. **Complexity**: The solution involves iterating through each person for each test case, resulting in a time complexity of O(t * n), which is efficient given the constraints.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    count = 0
    for num in a:
        if num == 0 and num < k:
            count += 1
    print(count)
```

### Explanation
- **Reading Input**: The code starts by reading the number of test cases. For each test case, it reads the number of people and the threshold `k`, followed by the list of gold values for each person.
- **Counting Gold**: For each gold value, it checks if the value is zero and less than `k`. If both conditions are met, it increments the count.
- **Output**: Finally, it prints the count for each test case, which represents the number of people who will receive gold from Robin Hood.
