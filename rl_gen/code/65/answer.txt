To solve this problem, we need to determine the winner of a game played by Alice and Bob using their respective permutations of integers. The game involves removing elements from both arrays alternately until only one element remains in each. Alice wins if the remaining elements are the same; otherwise, Bob wins.

### Approach
The key insight is that the winner can be determined by comparing the maximum elements of Alice's and Bob's permutations. The reasoning is as follows:
1. Alice and Bob take turns removing elements from their respective arrays until only one element remains.
2. The optimal strategy for both players ensures that Alice will try to maximize the chance of her remaining element matching Bob's, while Bob will try to minimize this chance.
3. The maximum element in Alice's array (max_a) and the maximum element in Bob's array (max_b) are critical because:
   - If Alice's maximum element is greater than or equal to Bob's maximum element, Alice can always ensure that her remaining element matches Bob's.
   - If Bob's maximum element is greater than Alice's, Bob can ensure that he wins.

Thus, the solution involves comparing the maximum elements of both arrays and determining the winner based on this comparison.

### Solution Code
```python
def determine_winner():
    import sys
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    results = []
    for _ in range(t):
        n = int(data[idx])
        idx += 1
        a = list(map(int, data[idx:idx+n]))
        idx += n
        b = list(map(int, data[idx:idx+n]))
        idx += n
        max_a = max(a)
        max_b = max(b)
        if max_a >= max_b:
            results.append("Alice")
        else:
            results.append("Bob")
    print('\n'.join(results))

determine_winner()
```

### Explanation
1. **Reading Input:** The input is read in one go for efficiency, especially given the constraints.
2. **Processing Each Test Case:** For each test case, we read the size of the permutations and the permutations themselves.
3. **Finding Maximum Elements:** We compute the maximum elements of both Alice's and Bob's permutations.
4. **Determining the Winner:** Based on the comparison of these maximum elements, we determine if Alice wins or Bob wins and store the result.
5. **Output the Results:** Finally, we print the results for all test cases.
