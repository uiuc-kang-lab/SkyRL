To solve this problem, we need to determine the function \( F(i) \) for each \( i \) from 1 to \( n \), where \( F(i) \) is the number of black integers reachable from \( i \) by following the permutation \( p \). The permutation \( p \) is given, and each integer is either black or white, represented by a binary string.

### Approach

1. **Permutation Cycles**: Each permutation can be decomposed into cycles. For example, if \( p = [3, 5, 6, 1, 2, 4] \), the permutation can be visualized as a graph where each node points to the next node in the permutation. This permutation will form cycles, and each cycle is a set of nodes that can be reached from each other by following the permutation.

2. **Cycle Detection**: Using a visited array, we can detect all cycles in the permutation. For each unvisited node, we traverse the cycle starting from that node, marking all nodes in the cycle as visited.

3. **Color Sum Calculation**: For each detected cycle, we calculate the sum of the black nodes (represented by '1' in the binary string). This sum is the value of \( F(i) \) for all nodes \( i \) in the cycle.

4. **Efficient Assignment**: Once all cycles and their corresponding black node sums are computed, we assign these sums to all nodes in the respective cycles.

### Solution Code

```python
import sys

def main():
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    for _ in range(t):
        n = int(data[idx])
        idx += 1
        p = list(map(int, data[idx:idx+n]))
        idx += n
        s = data[idx]
        idx += 1
        
        colors = [0] * (n + 1)
        for i in range(1, n+1):
            if s[i-1] == '1':
                colors[i] = 1
            else:
                colors[i] = 0
        
        visited = [False] * (n + 1)
        F = [0] * (n + 1)
        
        for i in range(1, n+1):
            if not visited[i]:
                cycle = []
                current = i
                while True:
                    if visited[current]:
                        break
                    visited[current] = True
                    cycle.append(current)
                    current = p[current - 1]  # p is 1-based, current is 1-based, p[current-1] is the next position
                sum_black = sum(colors[j] for j in cycle)
                for node in cycle:
                    F[node] = sum_black
        
        print(' '.join(map(str, F[1:n+1])))
        
if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints. The input is split into a list for easier processing.

2. **Color Array**: We create an array `colors` where each element is 1 if the corresponding position in the permutation is colored black, and 0 otherwise.

3. **Cycle Detection and Sum Calculation**: For each node, if it hasn't been visited, we traverse the cycle starting from that node. During this traversal, we compute the sum of black nodes in the cycle and store this sum for all nodes in the cycle.

4. **Output**: After processing all cycles, we print the results for each test case.
