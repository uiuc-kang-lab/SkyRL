To solve this problem, we need to determine the earliest moment when all rooms in an apartment have their lights turned on. Each room's lights are initially off and are installed at different times with a fixed period `k` after which they change their state.

### Approach
1. **Identify the Maximum Initial Time**: The first step is to find the maximum initial time `max_a` at which any room's chip is installed. This is because the earliest possible moment when all lights could be on is at or after this maximum time.
2. **Calculate Earliest On Time for Each Room**: For each room, compute the earliest time `t_i` at which its lights will be on. This is done by determining how many full periods `k` fit into the time difference between `max_a` and the room's installation time `a_i`.
3. **Determine the Earliest Common On Time**: The earliest time when all rooms' lights are on is the maximum of all `t_i` values computed in the previous step. This ensures that this time is within the on intervals of all rooms.

```python
        n, k = map(int, sys.stdin.readline().split())
        a = list(map(int, sys.stdin.readline().split()))
        max_a = max(a)
        max_t = 0
        for ai in a:
            m_i = (max_a - ai) // k
            t_i = ai + m_i * k
            if t_i > max_t:
                max_t = t_i
        print(max_t)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The code reads multiple test cases. For each test case, it reads the number of rooms `n`, the period `k`, and the list of times `a` when each room's chip was installed.
2. **Finding Maximum Initial Time**: The maximum value in the list `a` is computed to determine the earliest possible time when all rooms could potentially have their lights on.
3. **Calculating Earliest On Time for Each Room**: For each room, the code calculates the earliest time `t_i` at which the lights will be on by determining how many full periods `k` fit into the time difference between `max_a` and the room's installation time. This is done using integer division.
4. **Determining the Earliest Common On Time**: The maximum of all `t_i` values is taken as the result for each test case, ensuring that this time is within the on intervals of all rooms.
