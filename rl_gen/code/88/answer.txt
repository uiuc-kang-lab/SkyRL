To solve this problem, we need to construct an array of positive nonzero integers such that for every integer \( k \) from 1 to \( n \), the sum of the elements at indices that are multiples of \( k \) is divisible by \( k \). Each element in the array must be less than or equal to \( 10^5 \).

### Approach
The key insight to solve this problem is to recognize that if each element \( a_j \) in the array is set to \( j \) (where \( j \) is the index), then for any \( k \), the sum of elements at indices that are multiples of \( k \) will be a multiple of \( k \). This is because each element at a multiple of \( k \) is a multiple of \( k \), and thus their sum will also be a multiple of \( k \).

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    arr = list(range(1, n + 1))
    print(' '.join(map(str, arr)))
```

### Explanation
1. **Input Reading**: We first read the number of test cases \( t \).
2. **Array Construction**: For each test case, we read the integer \( n \) and construct an array where each element \( a_j \) is set to \( j \) (from 1 to \( n \)).
3. **Output**: We print the constructed array for each test case.

This approach ensures that the array meets the required conditions efficiently, with each element being a positive integer and ensuring the sum of elements at multiples of any \( k \) is divisible by \( k \).<｜end▁of▁sentence｜>
