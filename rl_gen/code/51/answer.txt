To solve this problem, we need to determine the minimum number of operations required to reduce a given integer \( n \) to zero by subtracting any power of \( k \) in each operation. 

### Approach
1. **Problem Analysis**: Each operation allows us to subtract \( k^x \) where \( x \) is a non-negative integer. The goal is to minimize the number of such operations. 
2. **Key Insight**: The optimal strategy is to subtract the largest possible power of \( k \) at each step. This greedy approach ensures that we reduce \( n \) as quickly as possible.
3. **Algorithm**:
   - For each test case, if \( k \) is 1, the result is simply \( n \) since each operation subtracts 1.
   - Otherwise, repeatedly subtract the largest possible power of \( k \) from \( n \) until \( n \) becomes zero, counting each operation.
4. **Complexity**: The algorithm efficiently handles each test case in \( O(\log n) \) time due to the logarithmic reduction in \( n \) at each step.

### Solution Code
```python
import sys

def min_operations(n, k):
    if k == 1:
        return n
    steps = 0
    while n > 0:
        max_power = 1
        x = 0
        while True:
            next_power = max_power * k
            if next_power > n:
                break
            max_power = next_power
            x += 1
        steps += 1
        n -= max_power
    return steps

t = int(sys.stdin.readline())
for _ in range(t):
    n, k = map(int, sys.stdin.readline().split())
    print(min_operations(n, k))
```

### Explanation
- **Reading Input**: The code reads multiple test cases.
- **Handling Special Case for \( k = 1 \)**: If \( k \) is 1, each operation subtracts 1, so the result is \( n \).
- **Greedy Subtraction**: For each \( n \), the largest power of \( k \) is subtracted in each step, reducing \( n \) efficiently.
