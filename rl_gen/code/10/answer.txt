So, the steps to solve the problem are:

1. For each test case, compute the depth of each leaf.

2. Find the maximum depth among all leaves, which is D.

3. Compute the sum of (D - d) for all leaves.

4. Compute the number of leaves at depth D, which is L_D.

5. The minimal number of operations is sum + (L - L_D).
