To solve this problem, we need to maximize the product of three integers \(a\), \(b\), and \(c\) after performing up to 5 increments on any of them. The goal is to determine the optimal increments to achieve the highest possible product.

### Approach
1. **Problem Analysis**: The product of three numbers is maximized when the numbers are as close to each other as possible. Given the constraint of up to 5 increments, we can distribute these increments among the three numbers to bring them closer to each other.
2. **Intuition**: By iterating through all possible distributions of increments (up to 5 increments in total), we can compute the new values of \(a\), \(b\), and \(c\) and their corresponding product. The optimal distribution will yield the highest product.
3. **Algorithm**: We generate all possible distributions of increments (x, y, z) such that \(x + y + z = 5\). For each distribution, we compute the new values of \(a\), \(b\), and \(c\), and their product. We keep track of the maximum product encountered.

### Solution Code
```python
t = int(input())
for _ in range(t):
    a, b, c = map(int, input().split())
    max_p = a * b * c
    for x in range(6):
        for y in range(6 - x):
            z = 5 - x - y
            if z < 0:
                continue
            new_a = a + x
            new_b = b + y
            new_c = c + z
            current = new_a * new_b * new_c
            if current > max_p:
                max_p = current
    print(max_p)
```

### Explanation
1. **Reading Input**: The number of test cases \(t\) is read first. For each test case, the values of \(a\), \(b\), and \(c\) are read.
2. **Initialization**: The initial product of \(a\), \(b\), and \(c\) is computed and stored in `max_p`.
3. **Generating Distributions**: Using nested loops, we generate all possible distributions of increments (x, y, z) such that \(x + y + z = 5\). For each distribution, we compute the new values of \(a\), \(b\), and \(c\).
4. **Computing Product**: For each distribution, the product of the new values is computed and compared with the current maximum product. If a higher product is found, it updates `max_p`.
5. **Output**: After evaluating all possible distributions for each test case, the maximum product is printed.
