To solve this problem, we need to determine if it is possible to equalize the sum of heights of mountains with and without snow caps on a given map using specific transformations. The transformations allow us to add an integer constant to all elements within a k x k submatrix.

### Approach
1. **Problem Analysis**: The key insight is that each transformation affects all elements in a k x k submatrix by the same constant value. This means the difference between the sum of heights of mountains with snow caps (sum_with) and those without (sum_without) will remain unchanged after any number of transformations. Therefore, the only way to make these sums equal is if they were already equal to begin with.

2. **Algorithm**: 
   - For each test case, read the map and the binary strings indicating the type of each mountain.
   - Calculate the sum of heights for mountains with snow caps (sum_with) and those without (sum_without).
   - Check if these sums are equal. If they are, print "YES"; otherwise, print "NO".

3. **Complexity**: The solution efficiently processes each test case in O(n * m) time, where n is the number of rows and m is the number of columns in the map. Given the constraints, this approach is optimal and feasible.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n, m, k = map(int, sys.stdin.readline().split())
        sum_with = 0
        sum_without = 0
        for _ in range(n):
            row = list(map(int, sys.stdin.readline().split()))
            s = sys.stdin.readline().strip()
            for j in range(m):
                if s[j] == '1':
                    sum_with += row[j]
                else:
                    sum_without += row[j]
        if sum_with == sum_without:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The code reads multiple test cases. For each test case, it reads the dimensions of the map and the size of the submatrix. It then reads the heights of the mountains and their respective binary strings indicating their type.
- **Sum Calculation**: For each cell in the map, the code calculates the sum of heights for mountains with snow caps (sum_with) and those without (sum_without).
- **Comparison**: Finally, the code checks if the sums are equal. If they are, it prints "YES"; otherwise, it prints "NO".
