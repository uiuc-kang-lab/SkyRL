To solve this problem, we need to efficiently handle a series of range update operations on an array and determine the maximum value after each operation. Given the constraints, a naive approach would be too slow, so we use a segment tree with lazy propagation to handle range updates and efficiently query the maximum value.

### Approach
1. **Segment Tree with Lazy Propagation**: This data structure allows us to perform range updates and point queries efficiently. Each node in the segment tree stores the maximum value in its range and a lazy value for deferred updates.
2. **Range Update Operations**: For each "+ l r" operation, we increment the range [l, r] by 1. For each "- l r" operation, we decrement the range [l, r] by 1. Using lazy propagation, we defer these updates to child nodes only when necessary.
3. **Query Maximum Value**: After each update, we query the maximum value in the entire array, which gives us the result for that operation.

### Solution Code
```python
import sys

class SegmentTree:
    def __init__(self, data):
        self.n = len(data)
        self.size = 1
        while self.size < self.n:
            self.size <<= 1
        self.tree = [0] * (2 * self.size)
        self.lazy = [0] * (2 * self.size)
        for i in range(self.n):
            self.tree[self.size + i] = data[i]
        for i in range(self.size - 1, 0, -1):
            self.tree[i] = max(self.tree[2 * i], self.tree[2 * i + 1])
    
    def push(self, node, l, r):
        if self.lazy[node] != 0:
            self.tree[2 * node] += self.lazy[node]
            self.tree[2 * node + 1] += self.lazy[node]
            self.lazy[2 * node] = self.lazy[node]
            self.lazy[2 * node + 1] = self.lazy[node]
            self.lazy[node] = 0
    
    def update_range(self, node, l, r, ul, ur, delta):
        if ur < ul or l > ur:
            return
        if ul <= l and r <= ur:
            self.tree[node] += delta
            self.lazy[node] += delta
            return
        self.push(node, l, r)
        mid = (l + r) // 2
        self.update_range(2 * node, l, mid, ul, ur, delta)
        self.update_range(2 * node + 1, mid + 1, r, ul, ur, delta)
        self.tree[node] = max(self.tree[2 * node], self.tree[2 * node + 1])
    
    def query_max(self):
        return self.tree[1]

def main():
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n = int(input[ptr])
        m = int(input[ptr + 1])
        ptr += 2
        a = list(map(int, input[ptr:ptr + n]))
        ptr += n
        st = SegmentTree(a)
        for __ in range(m):
            c = input[ptr]
            l = int(input[ptr + 1])
            r = int(input[ptr + 2])
            ptr += 3
            delta = 1 if c == '+' else -1
            st.update_range(1, 1, n, l, r, delta)
            max_val = st.query_max()
            print(max_val)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Segment Tree Initialization**: The segment tree is initialized with the given array. Each node in the tree stores the maximum value in its range and a lazy value for deferred updates.
2. **Range Update**: For each update, we use the segment tree's `update_range` method to apply the range update. This method handles both the current node and its children, propagating the lazy updates as needed.
3. **Query Maximum**: After each update, we query the maximum value in the entire array using the `query_max` method, which efficiently returns the maximum value after all updates for that test case.
