To solve this problem, we need to determine if a given string can be split into parts such that the first character of any part is different from the last character of any subsequent part. This ensures that the string is a "good string".

### Approach
The key insight is that if a string consists of all the same characters, it can only be split into a good string if its length is exactly 2. For any longer string with at least two different characters, we can always split it into a good string. This is because we can split the string into two parts: the first character and the rest of the string. The first part starts with the first character, and the rest of the string ends with a different character, ensuring the condition is met.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    s = input().strip()
    if len(set(s)) == 1:
        if n == 2:
            print("YES")
        else:
            print("NO")
    else:
        print("YES")
```

### Explanation
1. **Reading Input:** We start by reading the number of test cases.
2. **Check for Uniform Characters:** For each string, we check if all characters are the same by converting the string into a set and checking its length. If the set length is 1, it means all characters are the same.
3. **Decision Based on Length:** If all characters are the same, we check if the string length is exactly 2. If it is, we print "YES"; otherwise, we print "NO".
4. **General Case:** If the string contains at least two different characters, we print "YES" because we can always split such a string into a good string.
