To solve this problem, we need to compute the expected value of the product of two randomly picked elements from an array, and represent this expected value as a fraction in a specific modular form.

### Approach
1. **Understanding the Expected Value**: The expected value \( E \) of the product of two randomly picked elements from the array can be computed as the square of the sum of all elements divided by the square of the number of elements. This is because each element can be paired with itself and with every other element, leading to \( n^2 \) possible pairs.

2. **Modular Arithmetic**: Since the result needs to be presented in a specific modular form, we use modular arithmetic to handle large numbers efficiently. We compute the result modulo \( 10^9 + 7 \).

3. **Efficient Computation**: For each test case:
   - Compute the sum of the array.
   - Use modular arithmetic to compute the sum modulo \( 10^9 + 7 \).
   - Compute the numerator as the square of the sum modulo \( 10^9 + 7 \).
   - Compute the denominator as the square of the number of elements modulo \( 10^9 + 7 \).
   - Use modular inversion to compute the inverse of the denominator.
   - Multiply the numerator by the modular inverse of the denominator to get the result.

### Solution Code
```python
MOD = 10**9 + 7

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    s = sum(a)
    s_mod = s % MOD
    numerator = (s_mod * s_mod) % MOD
    n_mod = n % MOD
    denominator = (n_mod * n_mod) % MOD
    inv_denominator = pow(denominator, MOD - 2, MOD)
    result = (numerator * inv_denominator) % MOD
    print(result)
```

1. **Reading Input**: The input is read efficiently using standard input methods, especially important for handling large inputs.
2. **Sum Calculation**: The sum of the array elements is computed. This sum is then taken modulo \( 10^9 + 7 \) to handle large numbers.
3. **Numerator and Denominator**: The numerator is the square of the sum modulo \( 10^9 + 7 \), and the denominator is the square of the number of elements modulo \( 10^9 + 7 \).
4. **Modular Inverse**: Using Fermat's Little Theorem, the modular inverse of the denominator is computed, which is necessary for division in modular arithmetic.
5. **Result Calculation**: The result is obtained by multiplying the numerator with the modular inverse of the denominator, all taken modulo \( 10^9 + 7 \).
