To solve this problem, we need to determine the maximum possible rating that the last remaining fighter can preserve in a tournament where each battle reduces the rating of the eliminated fighter by the rating of the remaining fighter.

### Approach
The key insight is to minimize the total reduction in the rating of the last remaining fighter. This can be achieved by eliminating the fighters with the smallest initial ratings first. The reasoning is that eliminating the weakest fighters early on reduces the impact on the stronger fighters, thus preserving the higher ratings for the last remaining fighter.

The approach involves the following steps:
1. For each test case, read the number of fighters and their respective ratings.
2. Sort the ratings in non-decreasing order.
3. Sum the ratings of the first `n-1` fighters (the weakest ones).
4. Subtract this sum from the rating of the strongest fighter (last element in the sorted list).
5. The result is the maximum possible rating of the last remaining fighter.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    for _ in range(t):
        n = int(data[idx])
        idx += 1
        a = list(map(int, data[idx:idx + n]))
        idx += n
        a.sort()
        sum_first = sum(a[:n-1])
        print(a[-1] - sum_first)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input:** The input is read in one go for efficiency, especially given the constraints.
- **Sorting:** The ratings are sorted to easily access the smallest and largest values.
- **Summing Smallest Ratings:** The sum of the smallest `n-1` ratings is computed to determine the total reduction in the last remaining fighter's rating.
- **Calculating Result:** The result is obtained by subtracting the sum of the smallest `n-1` ratings from the largest rating, which gives the maximum possible rating for the last fighter.
