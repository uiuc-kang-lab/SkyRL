To solve this problem, we need to determine the minimum number of occupied diagonals when placing `k` chips on an `n x n` board. Each diagonal is defined by the sum of its row and column indices. The goal is to minimize the number of diagonals that contain at least one chip.

### Approach
1. **Understanding Diagonals**: Each diagonal on an `n x n` board can be identified by the sum of its row and column indices. For example, the diagonal sum `i + j` where `i` is the row index and `j` is the column index. The number of diagonals is `2n - 1`.

2. **Length of Diagonals**: For each sum `s` from 2 to `2n`, the length of the diagonal is:
   - If `s` is between 2 and `n + 1`, the length is `s - 1`.
   - If `s` is between `n + 2` and `2n`, the length is `2n + 1 - s`.

3. **Optimal Placement**: To minimize the number of occupied diagonals, we should place as many chips as possible on the longest diagonals first. This is done by sorting the lengths of all diagonals in descending order and iteratively placing chips on the longest diagonals until all `k` chips are placed.

4. **Special Case Handling**: If `k` is greater than or equal to the total number of diagonals (`2n - 1`), all diagonals must be occupied, so the result is simply `2n - 1`.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    if k == 0:
        print(0)
        continue
    total_diagonals = 2 * n - 1
    if k >= total_diagonals:
        print(total_diagonals)
        continue
    # Compute lengths of all diagonals
    lengths = []
    for s in range(2, 2 * n + 1):
        if s <= n + 1:
            l = s - 1
        else:
            l = 2 * n + 1 - s
        lengths.append(l)
    # Sort the lengths in descending order
    lengths.sort(reverse=True)
    count = 0
    remaining = k
    for l in lengths:
        if remaining <= 0:
            break
        take = min(l, remaining)
        count += 1
        remaining -= take
    print(count)
```

### Explanation
1. **Reading Input**: The code reads the number of test cases `t` and processes each test case individually.
2. **Edge Cases**: If `k` is 0, no chips are placed, so the result is 0. If `k` is greater than or equal to the total number of diagonals, all diagonals are occupied.
3. **Diagonal Length Calculation**: For each possible diagonal sum `s`, the code calculates the length of the diagonal.
4. **Sorting and Placement**: The lengths of the diagonals are sorted in descending order. The code then iteratively places chips on the longest diagonals first, minimizing the number of occupied diagonals.
5. **Output**: The result for each test case is printed, which is the minimum number of occupied diagonals.
