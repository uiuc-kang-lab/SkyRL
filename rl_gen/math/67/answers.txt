Given a set of data \( x_{1}, x_{2}, x_{3}, x_{4}, x_{5} \) with an average of 2, we need to find the average of another set of data \( 3x_{1}+1, 3x_{2}+1, 3x_{3}+1, 3x_{4}+1, 3x_{5}+1 \).

First, we know the average of the original data set is 2, so the sum of the original data points is:
\[
x_{1} + x_{2} + x_{3} + x_{4} + x_{5} = 2 \times 5 = 10
\]

For the new data set, each data point is transformed by multiplying by 3 and adding 1. Therefore, the sum of the new data points is:
\[
3x_{1} + 1 + 3x_{2} + 1 + 3x_{3} + 1 + 3x_{4} + 1 + 3x_{5} + 1 = 3(x_{1} + x_{2} + x_{3} + x_{4} + x_{5}) + 5 \times 1
\]
Substituting the sum of the original data points:
\[
3 \times 10 + 5 = 30 + 5 = 35
\]

The average of the new data set is then:
\[
\frac{35}{5} = 7
\]
