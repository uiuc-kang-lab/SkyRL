To solve the problem, we start by expressing the four-digit number \( N \) as \( N = 1000a + b \), where \( a \) is the leftmost digit (a thousands digit, so it can be from 1 to 9) and \( b \) is the remaining three-digit number (from 0 to 999). The problem states that removing the leftmost digit \( a \) gives the three-digit number \( b \), which is one-seventh of \( N \). Thus, we have:

\[ b = \frac{N}{7} \]

Substituting \( N \) with \( 1000a + b \), we get:

\[ b = \frac{1000a + b}{7} \]

Multiplying both sides by 7 to eliminate the denominator:

\[ 7b = 1000a + b \]

Subtracting \( b \) from both sides:

\[ 6b = 1000a \]

Dividing both sides by 6:

\[ b = \frac{500a}{3} \]

Since \( b \) must be an integer, \( \frac{500a}{3} \) must also be an integer. This implies that \( 500a \) must be divisible by 3. Analyzing \( 500 \mod 3 \):

\[ 500 \div 3 = 166 \text{ remainder } 2 \]

So, \( 500 \equiv 2 \mod 3 \). Therefore, \( 500a \equiv 2a \mod 3 \). For \( 2a \) to be divisible by 3, \( a \) must be a multiple of 3. The possible values for \( a \) (since it is a digit from 1 to 9) are 3, 6, and 9.

- For \( a = 3 \):
  \[ b = \frac{500 \times 3}{3} = 500 \]
  Thus, \( N = 1000 \times 3 + 500 = 3500 \).
- For \( a = 6 \):
  \[ b = \frac{500 \times 6}{3} = 1000 \]
  This is invalid because \( b \) must be a three-digit number.
- For \( a = 9 \):
  \[ b = \frac{500 \times 9}{3} = 1500 \]
  This is also invalid because \( b \) must be a three-digit number.

Therefore, the only valid solution is when \( a = 3 \) and \( b = 500 \), giving \( N = 3500 \).
