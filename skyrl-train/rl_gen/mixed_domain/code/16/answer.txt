The operation involves selecting an index `i` such that `a[i] = i` and removing the elements at `i` and `i+1` from the array. The goal is to maximize the number of such operations.

### Approach
The problem can be efficiently solved using a greedy algorithm. The key insight is to recognize that each valid operation corresponds to a non-overlapping interval in the array. Specifically, each valid operation is defined by an interval `[i, i+1]` where `a[i] = i`.

1. **Identify Valid Intervals**: For each element in the array, check if it satisfies the condition `a[i] = i+1` (considering the 1-based index). Collect these valid indices.
2. **Sort Intervals**: Sort the collected valid indices in increasing order.
3. **Greedy Selection**: Iterate through the sorted indices and count the maximum number of non-overlapping intervals. This is done by selecting the earliest ending interval that does not overlap with the previously selected interval.

### Solution Code
```python
def max_operations():
    import sys
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    for _ in range(t):
        n = int(data[idx])
        idx += 1
        a = list(map(int, data[idx:idx+n]))
        idx += n
        intervals = []
        for i in range(n):
            if a[i] == i + 1:
                intervals.append(i + 1)  # Convert to 1-based index
        intervals.sort()
        last_end = -1
        count = 0
        for i in intervals:
            if i > last_end:
                count += 1
                last_end = i
        print(count)

max_operations()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Identifying Valid Intervals**: For each element in the array, check if it meets the condition `a[i] == i + 1` (since the array is 0-based in the code, but the problem uses 1-based indices).
3. **Sorting Intervals**: The valid indices are sorted to facilitate the greedy selection of non-overlapping intervals.
4. **Greedy Selection**: Iterate through the sorted indices, and for each valid interval, check if it can be selected without overlapping with the previously selected interval. If it can, increment the count and update the end of the last selected interval.
