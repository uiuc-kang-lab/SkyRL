To solve this problem, we need to determine the largest value \( m \) such that the given array can be split into exactly \( k \) subarrays, each of which has the property that the product of the subarray's length and its maximum element equals \( m \).

### Approach
1. **Binary Search**: We use binary search to efficiently find the maximum value \( m \). The search range is from 0 to \( n^2 \) (since the maximum possible product of a subarray's length and its maximum element is \( n \times n \)).
2. **Can Split Function**: For each midpoint value \( m \) during the binary search, we check if the array can be split into exactly \( k \) subarrays where each subarray's product of length and maximum element equals \( m \). This is done using a helper function `can_split`.
3. **Helper Function**: The `can_split` function iterates through the array, maintaining the current subarray's maximum and length. For each element, it updates the current subarray's maximum and length or starts a new subarray if necessary. It checks if the current subarray's product equals \( m \) and counts how many such subarrays can be formed.

### Solution Code
```python
n, k = map(int, input().split())
a = list(map(int, input().split()))

def can_split(m):
    count = 0
    current_max = 0
    current_length = 0
    for num in a:
        if current_length == 0:
            current_max = num
            current_length = 1
        else:
            if num > current_max:
                current_max = num
                current_length += 1
            else:
                if current_max * current_length == m:
                    count += 1
                    current_max = num
                    current_length = 1
                else:
                    current_max = num
                    current_length += 1
    return count == k

low = 0
high = n * n
best = -1

while low <= high:
    mid = (low + high) // 2
    if can_split(mid):
        best = mid
        low = mid + 1
    else:
        high = mid - 1

print(best if best != -1 else -1)
```

### Explanation
