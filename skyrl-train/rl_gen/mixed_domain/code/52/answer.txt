To solve this problem, we need to maximize the expected value of winnings from a casino game by selecting a subset of games to play. Each game has a probability of winning and a corresponding reward. The goal is to find the subset of games that maximizes the expected value, which is the product of the probabilities of winning all selected games multiplied by the sum of their rewards.

### Approach
1. **Problem Analysis**: The expected value of winnings is given by the product of the probabilities of winning each selected game multiplied by the sum of their rewards. This can be simplified by recognizing that the product of probabilities can be represented using logarithms, which allows us to convert the problem into a more manageable form.

2. **Key Insight**: For each game, if the product of its probability and reward (p_i * w_i) is greater than 100, including it in the subset will increase the expected value. This is because (p_i / 100) * w_i > 1 implies that including the game increases the expected value.

3. **Algorithm**: 
   - Read the number of games.
   - For each game, check if p_i * w_i > 100. If true, include it in the subset.
   - Compute the product of (p_i / 100) for all included games.
   - Compute the sum of w_i for all included games.
   - The expected value is the product of the probabilities and the sum of rewards.

### Solution Code
```python
n = int(input())
product = 1.0
sum_w = 0.0
for _ in range(n):
    p, w = map(int, input().split())
    if p * w > 100:
        product *= p / 100.0
        sum_w += w
print("{0:.10f}".format(product * sum_w))
```

### Explanation
- **Reading Input**: The code reads the number of games and then iterates through each game to check if it should be included in the subset based on the condition p_i * w_i > 100.
- **Updating Product and Sum**: For each game that meets the condition, the product of probabilities is updated by multiplying with p_i / 100, and the sum of rewards is updated by adding w_i.
- **Calculating Expected Value**: The expected value is the product of the probabilities and the sum of rewards, which is then printed with a precision of 10 decimal places to ensure accuracy.

This approach ensures that we efficiently select the subset of games that maximizes the expected value while maintaining a time complexity of O(n), which is optimal given the problem constraints.<｜end▁of▁sentence｜>
