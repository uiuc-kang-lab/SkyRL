To solve this problem, we need to maximize the score by performing operations on a strip of cells where each cell contains a positive integer and a direction ('L' or 'R'). The goal is to select segments of cells such that each segment starts with 'L' and ends with 'R', and the segments do not overlap.

### Approach
1. **Identify Segments**: For each 'L' encountered, find the farthest 'R' to the right. This forms the longest possible segment starting with 'L' and ending with 'R'.
2. **Greedy Selection**: Use a greedy approach to select the largest possible segment starting from each 'L'. This ensures that we maximize the score by considering the largest possible segment each time.
3. **Efficient Calculation**: Precompute the farthest 'R' for each position using an array. This allows us to quickly determine the farthest 'R' for any starting position, reducing the time complexity.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    s = input().strip()
    farthest_R = [0] * n
    far = -1
    for i in range(n-1, -1, -1):
        if s[i] == 'R':
            far = i
        farthest_R[i] = far
    current = 0
    total = 0
    while current < n:
        if s[current] == 'L':
            j = farthest_R[current]
            if j == -1:
                break
            total += sum(a[current:j+1])
            current = j + 1
        else:
            current += 1
    print(total)
```

### Explanation
1. **Reading Input**: The input consists of multiple test cases. For each test case, we read the number of cells, the list of integers, and the string indicating the directions.
2. **Precompute Farthest 'R'**: We create an array `farthest_R` where each index `i` contains the farthest index `j` such that the character at `j` is 'R' and `j >= i`.
3. **Greedy Segment Selection**: Using a loop, we iterate through the string. For each 'L' encountered, we use the precomputed `farthest_R` to find the farthest 'R' and calculate the sum of the segment from the current position to this farthest 'R'.
4. **Update Current Position**: After processing a segment starting at `current`, we update `current` to the position right after the farthest 'R' to ensure the next segment starts after the current one ends.
5. **Output the Result**: The total score is accumulated and printed for each test case.
