To solve this problem, we need to calculate the expected value of the square of the XOR of a randomly constructed multiset \( S \) derived from two arrays \( a \) and \( p \). The result should be output modulo \( 10^9 + 7 \).

### Approach
1. **Bitwise Analysis**: The XOR of a set of numbers can be analyzed bit by bit. For each bit position \( k \), we determine the probability that this bit is set in the XOR result of the multiset \( S \).

2. **Probability Calculation**: For each bit \( k \), the probability that the bit is set in the XOR result is the sum of probabilities that each element \( a_i \) that has the \( k \)-th bit set is included in \( S \) and contributes to the bit being set. This probability is calculated as \( \frac{\text{sum of } p_i \text{ for all } a_i \text{ with the } k\text{-th bit set}}{10000} \).

3. **Sum of Probabilities**: The expected value of the square of the XOR result is the square of the sum of these probabilities for all bit positions. This is because the expected value of the square of a sum of independent random variables is the square of the sum of their expected values.

4. **Modular Arithmetic**: Since the result needs to be modulo \( 10^9 + 7 \), we use modular arithmetic to handle divisions. The modular inverse of 10000 is precomputed using Fermat's Little Theorem.

### Solution Code
```python
MOD = 10**9 + 7
inv_10000 = pow(10000, MOD - 2, MOD)

t = int(input())

    a = list(map(int, input().split()))

    ans = (sum_p * sum_p) % MOD
```
