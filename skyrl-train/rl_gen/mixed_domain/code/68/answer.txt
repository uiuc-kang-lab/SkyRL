### Approach
1. **Problem Analysis**: Each operation connects points in an arithmetic sequence. These operations can be represented as intervals on the number line. The goal is to determine how these intervals overlap to form connected components.

2. **Interval Representation**: Each operation can be represented as an interval `[a_i, a_i + k_i * d_i]` where `a_i` is the starting point, `d_i` is the step size, and `k_i` is the number of steps. This interval represents all points connected by that operation.

3. **Sorting and Merging Intervals**: To find the connected components, we need to merge overlapping or adjacent intervals. The number of merged intervals will give the number of connected components.

4. **Algorithm**:
   - For each test case, read the operations and convert them into intervals.
   - Sort these intervals based on their start points.
   - Merge overlapping or adjacent intervals to count the number of connected components.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    results = []
    
    for _ in range(t):
        n = int(data[idx])
        m = int(data[idx + 1])
        idx += 2
        
        intervals = []
        for __ in range(m):
            a = int(data[idx])
            d = int(data[idx + 1])
            k = int(data[idx + 2])
            idx += 3
            end = a + k * d
            intervals.append((a, end))
        
        intervals.sort()
        merged = []
        for interval in intervals:
            if not merged:
                merged.append(interval)
            else:
                last = merged[-1]
                if interval[0] <= last[1] + 1:
                    new_start = last[0]
                    new_end = max(last[1], interval[1])
                    merged[-1] = (new_start, new_end)
                else:
                    merged.append(interval)
        
        results.append(len(merged))
    
    sys.stdout.write('\n'.join(map(str, results)) + '\n')

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Interval Extraction**: For each operation, convert the arithmetic sequence into an interval.
3. **Sorting**: The intervals are sorted based on their start points to facilitate merging.
4. **Merging Intervals**: Iterate through the sorted intervals, merging them if they overlap or are adjacent.
5. **Result Collection**: The number of merged intervals is the number of connected components, which is collected and printed at the end.
