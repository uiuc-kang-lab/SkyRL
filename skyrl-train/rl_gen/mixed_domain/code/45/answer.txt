To solve this problem, we need to determine the minimum number of roads that must be maintained to ensure that all friendships between residents of Penacony are connected through maintained roads. The houses are arranged in a cycle, and we need to ensure that all given friendships are present in the maintained roads.

### Approach
1. **Graph Representation**: Represent the problem using a graph where each house is a node and each road is an edge. The initial setup is a cycle, ensuring all nodes are connected.
2. **Friendship Graph**: Construct a graph where each friendship is an edge. This graph may have multiple connected components.
3. **Connected Components**: The goal is to find the number of connected components in the friendship graph. Each connected component can be connected by maintaining one additional road.
4. **Minimum Roads to Maintain**: The minimum number of roads to maintain is the number of connected components minus one. This is because each connected component can be connected with one road, and we need to connect all components into a single connected graph.

### Solution Code
```python
import sys
from collections import deque

def main():
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    for _ in range(t):
        n = int(data[idx])
        m = int(data[idx + 1])
        idx += 2
        adj = [[] for _ in range(n + 1)]
        for _ in range(m):
            a = int(data[idx])
            b = int(data[idx + 1])
            idx += 2
            adj[a].append(b)
            adj[b].append(a)
        visited = [False] * (n + 1)
        count = 0
        for i in range(1, n + 1):
            if not visited[i]:
                count += 1
                queue = deque([i])
                visited[i] = True
                while queue:
                    u = queue.pop(0)
                    for v in adj[u]:
                        if not visited[v]:
                            visited[v] = True
                            queue.append(v)
        print(count - 1)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Graph Construction**: For each test case, an adjacency list is built to represent the graph of houses and roads.
3. **BFS for Connected Components**: Using BFS, we traverse each unvisited node to find all connected components. Each BFS operation marks nodes as visited.
4. **Counting Components**: The number of connected components is counted, and the result is the number of components minus one, which is the minimum number of roads to maintain.
