To solve this problem, we need to maximize the value of x after performing a series of operations on an array. The operations involve repeatedly merging two elements, appending their floor average, and removing the elements until only one element remains. The goal is to determine the maximum possible value of this final element.

### Approach
The key insight is to merge the two smallest elements in the array at each step. This approach minimizes the reduction in the sum of the array, thereby maximizing the final value. Here's the step-by-step approach:

1. **Heap Initialization**: Convert the array into a min-heap. This allows us to efficiently extract the two smallest elements each time.
2. **Merging Elements**: While the size of the heap is greater than 1, repeatedly extract the two smallest elements, compute their floor average, and insert this average back into the heap.
3. **Termination**: Once the heap size is reduced to 1, the remaining element is the maximum possible value of x.

### Solution Code
```python
import heapq

def maximize_x():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        heapq.heapify(a)
        while len(a) > 1:
            x = a[0]
            y = a[1]
            a = a[2:]
            m = (x + y) // 2
            heapq.heappush(a, m)

maximize_x()
```

3. **Efficiency**: Using a min-heap ensures that each extraction and insertion operation is efficient, making the solution scalable even for the upper limits of the input constraints.
