To solve this problem, we need to process a series of queries on an array where each query adds either +1 or -1 to an element. The goal is to ensure that every element remains non-negative and to minimize the sum of the array after all queries.

### Approach
1. **Initialization**: Start with an array of zeros, where each element is initially zero.
2. **Min-Heap Usage**: Use a min-heap to efficiently track and manage the smallest element in the array. This allows us to always add 1 to the smallest element, which helps in spreading out the additions and minimizing the maximum value.
3. **Processing Queries**: For each query, determine the current smallest element. Add 1 to this element and push the result back into the heap. This ensures that we are spreading the increments as evenly as possible across all elements.

### Solution Code
```python
import heapq

def main():
    import sys
    input = sys.stdin.read
    data = input().split()
    idx = 0
    n = int(data[idx])
    idx += 1
    q = int(data[idx])
    idx += 1
    heap = [0] * n
    heapq.heapify(heap)
    output = []
    for _ in range(q):
        x = int(data[idx])
        idx += 1
        y = int(data[idx])
        idx += 1
        min_val = heapq.heappop(heap)
        new_val = min_val + 1
        heapq.heappush(heap, new_val)
        output.append(str(new_val))
    print('\n'.join(output))

    main()
```
