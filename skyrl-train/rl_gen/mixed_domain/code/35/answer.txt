To solve this problem, we need to determine the minimum number of moves required for the teachers to catch David in a one-dimensional classroom. The classroom is represented as a line of cells, and both David and the teachers can move optimally to minimize the number of moves.

### Approach
1. **Problem Analysis**: David and the teachers start in distinct cells. Each move consists of David moving first, followed by all the teachers moving. The goal is to find the minimum number of moves required for the teachers to catch David, who is moving towards the teachers to avoid getting caught.

2. **Key Insight**: The critical factor in determining the minimum number of moves is the maximum distance between David's starting position and the positions of the teachers. This is because the teachers can move optimally to minimize the distance, and the worst-case scenario is when the teachers are initially farthest from David.

3. **Algorithm**: For each query, compute the maximum distance between David's starting position and each teacher's position. The minimum number of moves required for the teachers to catch David is this maximum distance.

    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    results = []
    for _ in range(t):
        n = int(data[idx])
        m = int(data[idx + 1])
        q = int(data[idx + 2])
        idx += 3
        b = list(map(int, data[idx:idx + m]))
        idx += m
        a_list = list(map(int, data[idx:idx + q]))
        idx += q
        max_dist = 0
        for a in a_list:
            current_max = 0
            for bi in b:
                d = abs(a - bi)
                if d > current_max:
                    current_max = d
            if current_max > max_dist:
                max_dist = current_max
        results.append(max_dist)
    
    sys.stdout.write('\n'.join(map(str, results)) + '\n')

if __name__ == "__main__":
    main()

### Explanation
- **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
- **Processing Each Test Case**: For each test case, read the number of cells, number of teachers, and number of queries. Then read the positions of the teachers and the queries.
- **Computing Maximum Distance**: For each query, compute the maximum distance between David's starting position and each teacher's position. This maximum distance is the minimum number of moves required for the teachers to catch David.
- **Output Results**: Collect the results for all queries and output them at once to minimize I/O operations.
