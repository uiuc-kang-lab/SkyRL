To solve this problem, we need to determine if each given string matches a given template. The template is defined by an array of integers, and a string matches the template if it meets three specific conditions.

### Approach
1. **Read Input:** We start by reading the number of test cases. For each test case, we read the array of integers and the strings to be checked against the template.
2. **Frequency Count of Array:** For each test case, we compute the frequency count of each integer in the array. This helps us quickly compare the counts of integers in any string against the array.
3. **Check Each String:** For each string, we first check if its length matches the length of the array. If not, it immediately fails. If the lengths match, we then compute the frequency count of the string and compare it with the frequency count of the array. If they match, the string matches the template.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline().strip())
        a = list(map(int, sys.stdin.readline().split()))
        m = int(sys.stdin.readline().strip())
        
        # Compute frequency of each element in 'a'
        a_val_counts = {}
        for num in a:
            a_val_counts[num] = a_val_counts.get(num, 0) + 1
        
        # Process each string
        for _ in range(m):
            s = sys.stdin.readline().strip()
            if len(s) != n:
                print("NO")
                continue
            s_val_counts = {}
            for c in s:
                s_val_counts[c] = s_val_counts.get(c, 0) + 1
            if s_val_counts == a_val_counts:
                print("YES")
            else:
                print("NO")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input:** The input is read using standard input methods. The number of test cases is read first, followed by the array and strings for each test case.
2. **Frequency Count:** For each array `a`, we create a dictionary to count the frequency of each integer. This allows us to quickly compare the structure of any string against the array.
3. **String Check:** For each string, we first check if its length matches the length of the array. If not, it is immediately rejected. If the lengths match, we compute the frequency of each character in the string and compare it with the frequency count of the array. A match is confirmed if both frequency dictionaries are identical.
