To solve this problem, we need to determine the minimum number of occupied diagonals when placing `k` chips on an `n x n` chessboard. A diagonal is defined as a set of cells where the sum of the row and column indices is constant. 

### Approach
1. **Identify Diagonals**: Each diagonal can be identified by the sum of its row and column indices, `s`. For an `n x n` chessboard, the range of `s` values is from 2 to `2n`.
2. **Count Cells in Diagonals**: For each diagonal identified by `s`, calculate the number of cells it contains:
   - If `s` is between 2 and `n+1`, the number of cells is `s-1`.
   - If `s` is greater than `n+1`, the number of cells is `2n - s`.
3. **Sort Diagonals by Cell Count**: Sort these diagonals in descending order based on the number of cells they contain.
4. **Accumulate Chips**: Starting from the diagonal with the most cells, accumulate chips until the total number of chips `k` is reached. The number of diagonals used in this process gives the minimum number of occupied diagonals.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    if k == 0:
        print(0)
        continue
    diagonals = []
    for s in range(2, 2 * n + 1):
        if s <= n + 1:
            cells = s - 1
        else:
            cells = 2 * n - s
        diagonals.append((s, cells))
    # Sort diagonals by the number of cells in descending order
    diagonals.sort(key=lambda x: -x[1])
    total = 0
    count = 0
    for s, cells in diagonals:
        if total >= k:
            break
        total += cells
        count += 1
    print(count)
```

### Explanation
1. **Reading Input**: The input consists of multiple test cases. For each test case, we read the values of `n` (side length of the chessboard) and `k` (number of chips).
2. **Edge Case Handling**: If `k` is 0, we immediately output 0 as no chips need to be placed.
3. **Diagonal Identification and Cell Count**: For each possible diagonal sum `s`, we calculate the number of cells it contains and store these diagonals along with their cell counts.
4. **Sorting Diagonals**: The diagonals are sorted in descending order based on the number of cells they contain.
5. **Accumulating Chips**: Starting from the diagonal with the most cells, we accumulate chips until we reach `k`. The number of such diagonals used is the result for that test case.
