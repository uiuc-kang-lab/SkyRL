To solve this problem, we need to determine if the Major Oak tree will have an even number of leaves in year \( n \). The tree starts with 1 leaf in year 1 and grows \( i^i \) new leaves in the \( i \)-th year. Leaves last for \( k \) years, so the leaves from year \( i \) are present in years \( i \) to \( i + k - 1 \).

### Approach
1. **Identify the Range of Years**: For each test case, determine the range of years \( i \) that contribute to the total number of leaves in year \( n \). This range is from \( a = \max(1, n - k + 1) \) to \( b = n \).
2. **Count Odd Year Contributions**: The sum of leaves in year \( n \) is even if and only if the number of odd-numbered years \( i \) in the range \([a, b]\) is even. This is because an odd number of odd contributions will result in an odd total, while an even number will result in an even total.
3. **Efficient Counting**: Use the formula to count the number of odd numbers in the range \([a, b]\) efficiently. The count of odd numbers between 1 and \( x \) is given by \( (x + 1) // 2 \). Adjust this formula to count the number of odd numbers between \( a \) and \( b \) by subtracting the count up to \( a-1 \) from the count up to \( b \).

### Solution Code
```python
t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    a = max(1, n - k + 1)
    b = n
    if a > b:
        print("YES")
        continue
    count = (b + 1) // 2 - (a) // 2
    if count % 2 == 0:
        print("YES")
    else:
        print("NO")
```

### Explanation
1. **Reading Input**: The code reads the number of test cases \( t \) and then processes each test case by reading \( n \) and \( k \).
2. **Determine Range**: For each test case, compute the range \([a, b]\) where \( a = \max(1, n - k + 1) \) and \( b = n \).
3. **Count Odd Contributions**: Calculate the number of odd contributions using the formula \((b + 1) // 2 - (a) // 2\).
4. **Determine Result**: Check if the count of odd contributions is even. If it is, print "YES"; otherwise, print "NO".

This approach efficiently determines the parity of the total number of leaves in year \( n \) without explicitly computing each contribution, making it suitable for large values of \( n \) and \( k \).<｜end▁of▁sentence｜>
