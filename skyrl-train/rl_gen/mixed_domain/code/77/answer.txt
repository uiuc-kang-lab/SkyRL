To solve this problem, we need to determine the maximum number of operations that can be performed on an array where each operation involves removing elements at specific indices. The goal is to find the optimal way to perform these operations such that the maximum number of operations is achieved.

### Approach
The problem can be efficiently solved using dynamic programming. The key idea is to use a dynamic programming array `dp` where `dp[i]` represents the maximum number of operations that can be performed starting from index `i` in the array.

1. **Dynamic Programming Array**: We initialize a dynamic programming array `dp` of size `n` (where `n` is the length of the array). Each element `dp[i]` will store the maximum number of operations that can be performed starting from index `i`.

2. **Recurrence Relation**: For each index `i` from `n-1` down to `0`:
   - If the element at index `i` is equal to `i+1` (i.e., it is the starting element for an operation), then we can perform an operation. The value of `dp[i]` is the maximum of either performing an operation at `i` and then proceeding to `i+2`, or not performing an operation at `i` and proceeding to `i+1`.
   - If the element at index `i` is not the starting element for an operation, then `dp[i]` is simply `dp[i+1]`.

3. **Result Extraction**: The result for each test case is found in `dp[0]`, which gives the maximum number of operations starting from the first element.

### Solution Code
```python
def max_operations():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n = int(input[ptr])
        ptr += 1
        a = list(map(int, input[ptr:ptr + n]))
        ptr += n
        dp = [0] * n
        for i in reversed(range(n)):
            if a[i] == (i + 1) and (i + 1) < n:
                dp[i] = max(dp[i + 1], 1 + dp[i + 2])
            else:
                dp[i] = dp[i + 1]
        print(dp[0])

max_operations()
```

- **Output the Result**: After processing all test cases, the result for each test case is printed.
