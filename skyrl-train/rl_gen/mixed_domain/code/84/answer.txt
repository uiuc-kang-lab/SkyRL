To solve this problem, we need to determine the number of starting cities from which we can conquer all cities by their deadlines. The cities are arranged in a row, and each subsequent city can only be conquered if it is adjacent to a conquered city.

### Approach
1. **Problem Analysis**:
   - We start from a city `s` and can conquer adjacent cities in subsequent steps.
   - Each city `i` has a deadline `a_i`, and we need to ensure that we conquer city `i` by time `a_i`.
   - The key insight is that the earliest time to reach city `i` from starting city `s` is the Manhattan distance `|i - s|`.

2. **Intuition**:
   - For each starting city `s`, we need to check if all cities `i` can be conquered by their respective deadlines.
   - The earliest time to reach city `i` from `s` is `|i - s|`. Thus, for each `i`, `a_i` must be at least `|i - s|`.

3. **Algorithm**:
   - For each test case, compute the minimum and maximum possible values of `s` such that for all cities `i`, `a_i >= |i - s|`.
   - This translates to finding the intersection of intervals `[max(1, i - a_i), min(n, i + a_i)]` for all `i`.
   - The valid starting cities are those `s` that lie within the intersection of all these intervals.

4. **Complexity**:
   - The algorithm runs in O(n) per test case, which is efficient given the constraints.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n = int(input[ptr])
        ptr += 1
        a = list(map(int, input[ptr:ptr+n]))
        ptr += n
        max_L = 0
        min_R = n + 1
        for i in range(1, n + 1):
            ai = a[i - 1]
            Li = max(1, i - ai)
            Ri = min(n, i + ai)
            if Li > max_L:
                max_L = Li
            if Ri < min_R:
                min_R = Ri
        if max_L > min_R:
            print(0)
        else:
            print(max(0, min_R - max_L + 1))

if __name__ == '__main__':
    main()
```

### Explanation
- **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
- **Initialization**: For each test case, initialize `max_L` to 0 and `min_R` to `n + 1`.
- **Loop Through Cities**: For each city `i`, compute the interval `[Li, Ri]` where `Li` is the earliest possible start time and `Ri` is the latest possible start time.
- **Update Bounds**: Track the maximum lower bound (`max_L`) and the minimum upper bound (`min_R`).
- **Check Validity**: If `max_L` exceeds `min_R`, no valid starting city exists. Otherwise, count the valid starting cities as `max_R - max_L + 1`.
