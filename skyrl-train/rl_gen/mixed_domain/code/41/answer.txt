So, the optimal strategy is to select as many non-overlapping intervals as possible, starting from the earliest possible.

This is the classic activity selection problem, where you select the earliest finishing time.

So, the approach would be:

1. Identify all the positions i where a_i =i.

2. Sort these positions in increasing order.

3. Greedily select the earliest possible i, then the next i that is at least i+2.

This way, we maximize the number of non-overlapping pairs.

Let's test this approach with the examples.

Example 1: array [1,2,3,4,5,6].

Positions where a_i =i: 1,2,3,4,5.

Sorted: 1,2,3,4,5.

Select i=1: then next can be i=3, then i=5.

Total operations: 3.

Which is correct.

Example 2: array [1,3,2,4].

Positions where a_i =i: 1,4.

Sorted:1,4.

Select i=1: next can be i=4.

So, two operations.

Which is correct.

Positions:1,2,3,4,5,6,7,8.

Greedy approach: select 1, then 3, then 5, then 7.

Total 4 operations.

Which is correct.
