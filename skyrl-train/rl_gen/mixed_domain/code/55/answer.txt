To solve this problem, we need to determine the earliest moment when all apartment rooms have their lights turned on. Each room's light is controlled by a chip that turns the light on for `k` minutes and then off for `k` minutes, repeating this cycle. The goal is to find the earliest time `T` such that all rooms have their lights on.

### Approach
1. **Identify the Maximum Time**: The earliest time `T` when all rooms can potentially have their lights on is the maximum time `a_i` at which a chip is installed. This is because for `T` to be the earliest time, it must be the latest chip installation time.
2. **Check Feasibility**: For each room, check if `T` falls within its on interval. The on interval for a room `i` starts at `a_i` and continues every `k` minutes. Thus, `T` must be greater than `a_i` and less than `a_i + k` for all rooms.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    t = int(input[idx])
    idx += 1
    for _ in range(t):
        n, k = int(input[idx]), int(input[idx+1])
        idx += 2
        a = list(map(int, input[idx:idx+n]))
        idx += n
        T = max(a)
        possible = True
        for x in a:
            if x + k <= T:
                possible = False
                break
        if possible:
            print(T)
        else:
            print(-1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Processing Each Test Case**: For each test case, we read the number of rooms `n` and the interval `k`. We then read the list of chip installation times `a`.
3. **Determine Earliest Time**: The earliest possible time `T` is the maximum value in `a`. We then check if `T` is within the on interval for all rooms.
4. **Feasibility Check**: For each room, if `T` is not within its on interval (i.e., `a_i + k <= T`), it is impossible for all rooms to have their lights on at `T`, and we return `-1`.
