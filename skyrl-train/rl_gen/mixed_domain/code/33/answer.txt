So, the question is, how to efficiently find, for each i, the earliest j >=i+1 where a[j] is the minimum in [i, j].

This can be done with a pre-processing step.

Idea:

We can precompute for each position i, the next occurrence of the minimum in the array, starting from i+1.

So, for each i, we can find j as the first position >=i+1 where a[j] is the minimum in [i, j].

This can be done by, for each i, finding the next minimum to the right.

We can precompute this using a stack or by traversing the array once.

Let me think about how to do this.

We can create an array 'next_min' where next_min[i] is the earliest j >=i where a[j] is the minimum in [i, j].

So, for each i, next_min[i] is the first j >=i where a[j] is the minimum in [i, j].

We can compute this by traversing the array from right to left.

Initialize next_min[n-1] = n-1.

For i from n-2 downto 0:

   if a[i] < a[next_min[i+1]]:

      next_min[i] = next_min[i+1]

   else:

      next_min[i] = i

So, this way, for each i, next_min[i] is the earliest j >=i where a[j] is the minimum in [i, j].
