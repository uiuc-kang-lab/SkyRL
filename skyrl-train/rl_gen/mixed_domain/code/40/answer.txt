To solve this problem, we need to determine if Alice can meet the Red Queen at a specific point (a, b) on the Red Queen's path. Alice moves according to a given string of directions, which repeats indefinitely. We need to check if Alice's path, which cycles through the given string, will ever land her exactly at the point (a, b).

### Approach
1. **Simulate Alice's Movement**: For each test case, simulate Alice's movement step by step according to the given string of directions.
2. **Track Position**: Keep track of Alice's position after each move. If at any point she reaches the target point (a, b), immediately conclude that she will meet the Red Queen.
3. **Check After Each Move**: After each move, check if Alice's position matches the target point. If it does, output "YES".
4. **Check After Full Cycle**: If Alice does not reach the target point during the first pass through the string, simulate the movement again for the entire string to check if she reaches the target point again.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n, a, b = map(int, input().split())
    s = input().strip()
    
    x, y = 0, 0
    found = False
    
    # First pass through the string
    for move in s:
        if move == 'N':
            y += 1
        elif move == 'E':
            x += 1
        elif move == 'S':
            y -= 1
        elif move == 'W':
            x -= 1
        if x == a and y == b:
            found = True
            break
    
    if found:
        print("YES")
        continue
    
    # Second pass through the string to check the final position
    x, y = 0, 0
    for move in s:
        if move == 'N':
            y += 1
        elif move == 'E':
            x += 1
        elif move == 'S':
            y -= 1
        elif move == 'W':
            x -= 1
        if x == a and y == b:
            found = True
            break
    
    if found:
        print("YES")
    else:
        print("NO")
```

### Explanation
1. **Reading Input**: The code reads the number of test cases and processes each test case individually.
2. **Simulating Movement**: For each test case, the string of directions is processed to simulate Alice's movement. After each move, the code checks if Alice has reached the target point (a, b).
3. **Immediate Check**: If Alice reaches the target point during the first traversal of the string, the result is immediately "YES".
4. **Final Check**: If Alice does not reach the target point during the first traversal, the code processes the entire string again to ensure she could potentially reach the target point at the end of a full cycle of directions.
5. **Output Result**: Based on the checks, the result for each test case is printed as "YES" or "NO".
