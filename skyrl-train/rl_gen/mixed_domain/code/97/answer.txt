2. For each column, determine the number of A's (a_i) and J's (j_i).

3. Split the grid into runs of consecutive A's and J's.

4. For each run of A's of length l, compute the maximum triplets as min(l // 2, j), where j is the number of J's in the run.

5. For each run of J's of length m, compute the maximum triplets as min(m // 2, l), where l is the number of A's in the run.

6. Sum all these to get the maximum votes for A.

So, min(1//2, 1) = 0.

So, no triplet from A's.

Length m=1, l=1.
