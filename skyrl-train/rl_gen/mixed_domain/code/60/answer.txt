To solve this problem, we need to find the maximum number of petals a bouquet can have while ensuring that the difference in the number of petals between any two flowers in the bouquet does not exceed one. Additionally, the total cost of the bouquet must not exceed a given amount.

### Approach
1. **Sort the Flowers**: First, we sort the array of petals in non-decreasing order. This helps in efficiently finding the largest possible subarray where the difference between the maximum and minimum number of petals is at most one.
2. **Prefix Sum Array**: Compute a prefix sum array to quickly calculate the sum of petals in any subarray. This allows us to efficiently determine the sum of petals for any given range.
3. **Binary Search for Maximum Sum**: For each starting index in the sorted array, use binary search to find the farthest index such that the sum of petals from the starting index to this farthest index does not exceed the given cost. Track the maximum sum obtained from these subarrays.

### Solution Code
```python
import bisect

def main():
    import sys
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    for _ in range(t):
        n = int(data[idx])
        m = int(data[idx + 1])
        idx += 2
        a = list(map(int, data[idx:idx + n]))
        idx += n
        a.sort()
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + a[i]
        max_petal = 0
        for i in range(n):
            target = prefix[i] + m
            j = bisect.bisect_right(prefix, target, i + 1, n) - 1
            current_sum = prefix[j + 1] - prefix[i]
            if current_sum > max_petal:
                max_petal = current_sum
        print(max_petal)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Sorting**: The flowers are sorted to facilitate the sliding window approach where we can efficiently find the maximum number of petals within a valid range.
2. **Prefix Sum Array**: This array helps in quickly calculating the sum of petals in any subarray. The prefix sum at index `i` gives the sum of the first `i` elements.
3. **Binary Search**: For each starting index `i`, we use binary search to find the farthest index `j` such that the sum of petals from `i` to `j` does not exceed the given cost `m`. This ensures that we efficiently find the maximum valid subarray sum.

This approach ensures that we efficiently find the optimal bouquet while adhering to the constraints, making it suitable for large input sizes.<｜end▁of▁sentence｜>
