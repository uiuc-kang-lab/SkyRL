To solve this problem, we need to insert exactly one lowercase Latin letter into a given password string to maximize the time it takes to type the password. The time calculation is based on the typing rules where the first character takes 2 seconds, and each subsequent character takes 1 second if it is the same as the previous character, otherwise 2 seconds.

### Approach
1. **Understand the Typing Time Calculation**: The time to type a password starts at 2 seconds for the first character. Each subsequent character adds 1 second if it is the same as the previous character, otherwise 2 seconds.
2. **Insertion Strategy**: For each test case, consider all possible positions to insert a character (from the beginning to the end of the string) and all 26 lowercase Latin letters. For each insertion, compute the typing time and keep track of the maximum time.
3. **Efficiency Considerations**: Given the constraints (string length up to 10), the solution is efficient as the number of possible insertions is manageable (10 positions * 26 letters = 260 possibilities per test case).

### Solution Code
```python
t = int(input())
for _ in range(t):
    s = input().strip()
    max_time = -1
    best_t = s
    for i in range(len(s) + 1):
        for c in 'abcdefghijklmnopqrstuvwxyz':
            t_new = s[:i] + c + s[i:]
            current_time = 2
            prev = t_new[0]
            for char in t_new[1:]:
                if char == prev:
                    current_time += 1
                else:
                    current_time += 2
                prev = char
            if current_time > max_time:
                max_time = current_time
                best_t = t_new
    print(best_t)
```

### Explanation
1. **Reading Input**: The number of test cases is read first. For each test case, the password string is read.
2. **Iterate Over Insertion Positions**: For each position in the string (from 0 to the length of the string), consider inserting each lowercase letter.
3. **Compute Typing Time**: For each new string formed by inserting a character, compute the typing time using the given rules.
4. **Track Maximum Time**: Keep track of the maximum typing time and the corresponding string that achieves this time.
5. **Output the Result**: After evaluating all possible insertions, print the string that results in the maximum typing time for each test case.
