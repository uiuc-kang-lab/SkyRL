To solve this problem, we need to determine the winner of a game played by Sakurako and Kosuke, who take turns moving a dot on a coordinate line. The dot starts at position 0, and the game continues while the absolute value of the dot's position does not exceed a given number \( n \). Sakurako moves the dot in the negative direction, while Kosuke moves it in the positive direction. The game ends when the absolute value of the dot's position exceeds \( n \).

### Approach
1. **Understanding the Moves**: Sakurako and Kosuke take turns moving the dot. Sakurako moves the dot by an odd number in the negative direction, while Kosuke moves it by the same odd number in the positive direction. The sequence of moves alternates between them.
2. **Sum of Moves**: The position of the dot after \( m \) moves can be determined by the sum of the moves. The sum of the moves alternates between negative and positive and follows a specific pattern. After \( m \) moves, the position of the dot is given by \( (-1)^m \times m \).
3. **Game Termination Condition**: The game ends when the absolute value of the dot's position exceeds \( n \). This happens when \( m \) exceeds \( n \), as the position after \( m \) moves is \( m \) if \( m \) is odd and \( -m \) if \( m \) is even, both of which have an absolute value of \( m \).
4. **Determining the Winner**: The last move is made by the player who starts the game if \( m \) is odd (Sakurako) or Kosuke if \( m \) is even.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    if n % 2 == 0:
        print("Kosuke")
    else:
        print("Sakurako")
```

### Explanation
- **Input Reading**: The code reads the number of test cases \( t \) and then processes each test case by reading \( n \).
- **Determine Winner**: For each \( n \), the code checks if \( n \) is even or odd. If \( n \) is even, Kosuke makes the last move; if odd, Sakurako does.
- **Output**: The result for each test case is printed based on whether \( n \) is even or odd.
