If s <0: output 0.

Else:

Find the maximum k such that (k-1)*k <= 2*s.

We can compute this using binary search.

So, the code would be:

import math

t = int(input())
for _ in range(t):
    l, r = map(int, input().split())
    s = r - l
    if s <0:
        print(0)
        continue
    low = 1
    high = 2 * 10**9  # since r can be up to 1e9, s can be up to 1e9, k can be up to about 4e4 (since (4e4)^2 is 1.6e9, so 2*s is 3.2e9, k can be up to approx 4e4.

    best = 0
    while low <= high:
        mid = (low + high) //2
        product = mid * (mid -1)
        if product <= 2*s:
            best = mid
            low = mid +1
        else:
            high = mid -1
    print(best)
